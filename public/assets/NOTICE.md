# Aset template SILAP

CSS Bootstrap/Sneat dan font Boxicons pada direktori ini digunakan kembali dari template SILAP lama sesuai permintaan pengguna.

Sumber lokal: D:.Learningsilappublicassets.

Hanya core.css, theme-default.css, styles.css, boxicons.css dan boxicons.woff2 yang disalin pada fondasi awal. Komentar hak cipta/lisensi yang tersedia di berkas sumber dipertahankan. Tidak ada foto siswa atau data storage lama yang disalin.

Referensi font pada boxicons.css disesuaikan ke berkas WOFF2 lokal; tidak memakai URL mirror berakhiran .html dari sumber lama. Lisensi proyek tidak menggantikan ketentuan lisensi aset pihak ketiga. Inventaris lisensi/dependensi tambahan dilanjutkan ketika komponen template lain diperlukan.
